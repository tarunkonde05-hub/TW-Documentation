Detailed Description

Prints prefixed, level-tagged messages to the console.

Example:

Logger log("[Main]", LogLevel::WARNING);
log.log(LogLevel::INFO, "hidden"); // below WARNING, not printed
log.log(LogLevel::ERROR, "printed"); // [Main] [ERROR] printed
LogLevel::WARNING
@ WARNING
Something unusual happened but the program can continue.
LogLevel::INFO
@ INFO
Normal progress messages.
LogLevel::ERROR
@ ERROR
An operation failed.
